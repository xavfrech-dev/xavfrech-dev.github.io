Step-by-step install

  1. Nothing to install: the game starts right in the tab.
  2. On a computer you can also install it from the browser (“Install” in the address bar of Chrome or Edge).

Windows Your device

Windows 10 and 11, 64-bit. Installs for your user account, no administrator rights needed.

Download (.exe)

File: REALMSHARD-Windows-Setup.exe · Size: 257 MB

SHA-256: ba0553000f5afc2f53078cc34a296f223c9c4e9a31e9100c1179b8d4093974c3

Step-by-step install

  1. Download the file. If the browser says it is not commonly downloaded, choose “Keep”.
  2. Run it. If Windows SmartScreen shows “Windows protected your PC”, click “More info”, then “Run anyway”. The warning comes from the lack of a paid certificate, not from a detected problem.
  3. If Windows 11 Smart App Control is on, it blocks the installer with no way around it: play in your browser instead.
  • Update: download the new version and install it over the old one; your progress is kept.
  • Uninstall: Settings › Apps › REALMSHARD.

macOS Your device

Universal app: Apple silicon and Intel.

Download (.dmg)

File: REALMSHARD-macOS.dmg · Size: 365.6 MB

SHA-256: 321933b9101bdf384b926fe96a385d608c21a314f6d075d5b6cc519a28547226

Step-by-step install

  1. Open the .dmg file and drag REALMSHARD into the Applications folder.
  2. macOS 15 and later: launch the app once (macOS blocks it), then open System Settings › Privacy & Security and click “Open Anyway” next to REALMSHARD.
  3. macOS 14 and earlier: right-click (or Control-click) the app in Applications, choose “Open”, then confirm.
  4. Last resort, in Terminal: xattr -dr com.apple.quarantine /Applications/REALMSHARD.app
  • The app is not notarised by Apple: notarisation requires an Apple Developer account ($99 a year).

iPhone and iPad Your device

No app to download: Apple only allows installs through the App Store or TestFlight, which require an Apple Developer account.

Open the game

Step-by-step install

  1. Open Safari and go to xavfrech-dev.github.io/realmshard.
  2. Tap the Share button, then “Add to Home Screen”.
  3. Launch REALMSHARD from your Home Screen: the game opens full screen, like an app.

Why these warnings?

Signing an app is expensive: a certificate for Windows, an Apple Developer account at $99 a year for macOS. REALMSHARD is a free fan project; its files are not signed by a known publisher, hence the warnings from Windows, macOS and Android. They all come from the releases page of the game’s public GitHub repository, and their SHA-256 fingerprints are published so you can check them.

Check a file

Every release publishes a SHA256SUMS.txt file with the fingerprint of each file. Compare it with the one of your download:

Windows (PowerShell):
Get-FileHash .\REALMSHARD-Windows-Setup.exe -Algorithm SHA256

macOS (Terminal):
shasum -a 256 REALMSHARD-macOS.dmg
