REALMSHARD herunterladen

REALMSHARD ist überall kostenlos. Am einfachsten spielst du im Browser, ganz ohne Installation; die Apps enthalten dasselbe Spiel.

Version 0.1.2, veröffentlicht am 1. November 2026.

Browser Dein Gerät

Aktuelles Chrome, Edge, Firefox oder Safari, auf Computer, Tablet oder Handy.

Jetzt spielen

Installation Schritt für Schritt

  1. Keine Installation: Das Spiel startet direkt im Tab.
  2. Am Computer kannst du es auch aus dem Browser installieren („Installieren“ in der Adressleiste von Chrome oder Edge).

Windows Dein Gerät

Windows 10 und 11, 64 Bit. Installation nur für dein Benutzerkonto, ohne Administratorrechte.

Herunterladen (.exe)

Datei: REALMSHARD-Windows-Setup.exe · Größe: 256,7 MB

SHA-256: 2ef724cc44bd8fa630252b76e35b38ffbac3c15e25fb6f3616415f0415a4a7f9

Installation Schritt für Schritt

  1. Lade die Datei herunter. Meldet der Browser, dass sie selten heruntergeladen wird, wähle „Beibehalten“.
  2. Starte sie. Zeigt Windows SmartScreen „Der Computer wurde durch Windows geschützt“, klicke auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“. Die Warnung kommt vom fehlenden kostenpflichtigen Zertifikat, nicht von einem gefundenen Problem.
  3. Ist die intelligente App-Steuerung von Windows 11 aktiv, blockiert sie die Installation ohne jede Umgehung: Spiel dann im Browser.
  • Aktualisieren: Lade die neue Version herunter und installiere sie über die alte; dein Fortschritt bleibt erhalten.
  • Deinstallieren: Einstellungen › Apps › REALMSHARD.

macOS Dein Gerät

Universelle App: Apple-Chips und Intel.

Herunterladen (.dmg)

Datei: REALMSHARD-macOS.dmg · Größe: 365,2 MB

SHA-256: 3a695132b36d348e27de98b7fb02ffdb184f0773b677923cea217e9a9d9b8d9a

Installation Schritt für Schritt

  1. Öffne die .dmg-Datei und ziehe REALMSHARD in den Ordner „Programme“.
  2. macOS 15 und neuer: Starte die App einmal (macOS blockiert sie), öffne dann Systemeinstellungen › Datenschutz & Sicherheit und klicke neben REALMSHARD auf „Dennoch öffnen“.
  3. macOS 14 und älter: Klicke mit der rechten Maustaste (oder bei gedrückter Ctrl-Taste) auf die App in „Programme“, wähle „Öffnen“ und bestätige.
  4. Als letzter Ausweg, im Terminal: xattr -dr com.apple.quarantine /Applications/REALMSHARD.app
  • Die App ist nicht von Apple notariell beglaubigt: Dafür braucht es ein Apple-Developer-Konto (99 $ im Jahr).

Installation Schritt für Schritt

  1. Hast du eine alte Test-APK von REALMSHARD installiert, deinstalliere sie zuerst.
  2. Lade die Datei mit deinem Browser herunter und öffne sie. Android fragt, ob dieser Browser „Unbekannte Apps installieren“ darf: Erlaube es.
  3. Zeigt Play Protect eine Warnung, tippe auf „Weitere Details“ und dann auf „Trotzdem installieren“.
  • Aktualisieren: Installiere die neue APK über die alte (gleicher Signaturschlüssel); dein Fortschritt bleibt erhalten.

iPhone und iPad Dein Gerät

Keine App zum Herunterladen: Apple erlaubt Installationen nur über den App Store oder TestFlight, und beide verlangen ein Apple-Developer-Konto.

Spiel öffnen

Installation Schritt für Schritt

  1. Öffne Safari und rufe xavfrech-dev.github.io/realmshard auf.
  2. Tippe auf „Teilen“ und dann auf „Zum Home-Bildschirm“.
  3. Starte REALMSHARD vom Home-Bildschirm: Das Spiel öffnet sich im Vollbild, wie eine App.

Warum diese Warnungen?

Eine App zu signieren ist teuer: ein Zertifikat für Windows, ein Apple-Developer-Konto für 99 $ im Jahr für macOS. REALMSHARD ist ein kostenloses Fanprojekt; seine Dateien sind nicht von einem bekannten Herausgeber signiert, daher die Warnungen von Windows, macOS und Android. Alle Dateien stammen von der Versionsseite des öffentlichen GitHub-Repositorys des Spiels, und ihre SHA-256-Prüfsummen werden veröffentlicht, damit du sie prüfen kannst.

Eine Datei prüfen

Jede Version veröffentlicht eine Datei SHA256SUMS.txt mit der Prüfsumme jeder Datei. Vergleiche sie mit der deines Downloads:

Windows (PowerShell):
Get-FileHash .\REALMSHARD-Windows-Setup.exe -Algorithm SHA256

macOS (Terminal):
shasum -a 256 REALMSHARD-macOS.dmg
