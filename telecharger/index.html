Télécharger REALMSHARD

REALMSHARD est gratuit partout. Le plus simple est de jouer dans le navigateur, sans rien installer ; les applis contiennent le même jeu.

Version 0.1.3, publiée le 1 novembre 2026.

Navigateur Ton appareil

Chrome, Edge, Firefox ou Safari récents, sur ordinateur, tablette ou téléphone.

Jouer maintenant

Installation pas à pas

  1. Rien à installer : le jeu se lance directement dans l’onglet.
  2. Sur ordinateur, tu peux aussi l’installer depuis le navigateur (« Installer » dans la barre d’adresse de Chrome ou d’Edge).

Windows Ton appareil

Windows 10 et 11, 64 bits. Installation pour ton compte, sans droits d’administrateur.

Télécharger (.exe)

Fichier : REALMSHARD-Windows-Setup.exe · Taille : 257 Mo

SHA-256 : ba0553000f5afc2f53078cc34a296f223c9c4e9a31e9100c1179b8d4093974c3

Installation pas à pas

  1. Télécharge le fichier. Si le navigateur indique qu’il est rarement téléchargé, choisis « Conserver ».
  2. Lance-le. Si Windows SmartScreen affiche « Windows a protégé votre ordinateur », clique sur « Informations complémentaires », puis sur « Exécuter quand même ». L’avertissement vient de l’absence de certificat payant, pas d’un problème détecté.
  3. Si le Contrôle intelligent des applications de Windows 11 est actif, il bloque l’installation sans aucun contournement : joue alors dans le navigateur.
  • Mise à jour : télécharge la nouvelle version et installe-la par-dessus ; ta progression est conservée.
  • Désinstaller : Paramètres › Applications › REALMSHARD.

macOS Ton appareil

Appli universelle : puces Apple et Intel.

Télécharger (.dmg)

Fichier : REALMSHARD-macOS.dmg · Taille : 365,6 Mo

SHA-256 : 321933b9101bdf384b926fe96a385d608c21a314f6d075d5b6cc519a28547226

Installation pas à pas

  1. Ouvre le fichier .dmg et glisse REALMSHARD dans le dossier Applications.
  2. macOS 15 et plus récent : lance l’appli une première fois (macOS la bloque), puis ouvre Réglages Système › Confidentialité et sécurité et clique sur « Ouvrir quand même » en face de REALMSHARD.
  3. macOS 14 et plus ancien : fais un clic droit (ou Contrôle-clic) sur l’appli dans Applications, choisis « Ouvrir », puis confirme.
  4. En dernier recours, dans le Terminal : xattr -dr com.apple.quarantine /Applications/REALMSHARD.app
  • L’appli n’est pas notarisée par Apple : la notarisation demande un compte Apple Developer (99 $ par an).

Installation pas à pas

  1. Si tu as installé un ancien APK de test de REALMSHARD, désinstalle-le d’abord.
  2. Télécharge le fichier avec ton navigateur, puis ouvre-le. Android te demande d’autoriser « Installer des applis inconnues » pour ce navigateur : autorise-le.
  3. Si Play Protect affiche un avertissement, touche « Plus de détails », puis « Installer quand même ».
  • Mise à jour : installe le nouvel APK par-dessus l’ancien (même clé de signature) ; ta progression est conservée.

iPhone et iPad Ton appareil

Aucune appli à télécharger : Apple n’autorise l’installation que par l’App Store ou TestFlight, qui demandent un compte Apple Developer.

Ouvrir le jeu

Installation pas à pas

  1. Ouvre Safari et va sur xavfrech-dev.github.io/realmshard.
  2. Touche le bouton Partager, puis « Sur l’écran d’accueil ».
  3. Lance REALMSHARD depuis l’écran d’accueil : le jeu s’ouvre en plein écran, comme une appli.

Pourquoi ces avertissements ?

Signer une appli coûte cher : un certificat pour Windows, un compte Apple Developer à 99 $ par an pour macOS. REALMSHARD est un projet de fan gratuit ; ses fichiers ne sont pas signés par un éditeur reconnu, d’où les avertissements de Windows, de macOS et d’Android. Ils viennent tous de la page des versions du dépôt GitHub public du jeu, et leur empreinte SHA-256 est publiée pour que tu puisses les vérifier.

Vérifier un fichier

Chaque version publie un fichier SHA256SUMS.txt avec l’empreinte de chaque fichier. Compare-la avec celle de ton téléchargement :

Windows (PowerShell) :
Get-FileHash .\REALMSHARD-Windows-Setup.exe -Algorithm SHA256

macOS (Terminal) :
shasum -a 256 REALMSHARD-macOS.dmg
